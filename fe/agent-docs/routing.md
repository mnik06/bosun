# Routing

React Router v7 in framework mode, running as a pure **SPA** (`ssr: false` in
`react-router.config.ts`). Routes are declared programmatically in `app/routes.ts`; there is no
`app/routes/` folder and no file-based routing. Vercel rewrites every non-asset path to
`index.html` (`vercel.json`).

## The route tree

```ts
// app/routes.ts
export default [
	layout('views/auth-layout/auth-layout.tsx', [route('login', 'views/login/login-page.tsx')]),
	layout('views/app-layout/app-layout.tsx', [
		layout('views/leader-layout/leader-layout.tsx', [
			index('views/machines/machines-page.tsx'),
			route('machines/:machineId', 'views/machine-detail/machine-detail-page.tsx'),
			route('settings', 'views/settings/settings-page.tsx'),
			route('github/callback', 'views/github-callback/github-callback-page.tsx'),
			route('members', 'views/members/members-page.tsx')
		]),
		layout('views/app-owner-layout/app-owner-layout.tsx', [
			route('projects', 'views/projects/projects-page.tsx')
		]),
		route('plans', 'views/plans/plans-page.tsx'),
		route('plans/new', 'views/plan-draft/plan-draft-page.tsx'),
		route('plans/:planId', 'views/plan-detail/plan-page.tsx')
	])
] satisfies RouteConfig
```

What each layout does — put a new route under the one whose gate it needs:

- **`AuthLayout`** — anonymous only; an authenticated session redirects to `/`.
- **`AppLayout`** — authenticated only (anonymous → `/login`). Mounts `ActiveProjectProvider`,
  waits for a project, then renders the `AppShell` (header, rail, mobile bottom bar) and the three
  socket providers around `<Outlet />`.
- **`LeaderLayout`** — `isLeader` only, else → `/plans`.
- **`AppOwnerLayout`** — `me.isAppOwner` only, else → `/plans`; waits on `useMeQuery` first so a
  real app owner is not bounced on reload.

Access guards are always a pathless layout declared once around the routes they cover — never a
check inside each page. When a route is added, add its nav entry to
`widgets/app-nav/lib/nav-links.ts` if it is a top-level destination (with `leaderOnly` /
`appOwnerOnly` matching its layout), and to `LIST_ROUTES` in
`entities/project/lib/project-switch-path.ts` if a project switch should land on it.

## View file = route component

Every route points at a file under `app/views/<view>/` (see `slice-views.md`). It owns the default
export; route params come from `Route.ComponentProps`, search params from `useSearchParams`.

## `+types/` imports

A route file imports its generated types from the sibling `./+types/<file>` and nowhere else:

```ts
import type { Route } from './+types/machine-detail-page'
```

They are generated by `react-router typegen`, which `pnpm typecheck` runs first — run it after
adding or renaming a route.
